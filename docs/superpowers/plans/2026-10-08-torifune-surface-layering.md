# 鸟船生态环与主轴外表面层次调整计划

> **执行说明：** 用户已认可“生态环连续大板面、局部独立护罩；主轴分段与服务区保留外挂层次”的方向。用户已确认实施（2026-10-08），本文件记录调整参数及步骤，由主 agent 使用 `superpowers:executing-plans` 实施，不委派实现任务。

**Goal:** 保留现有曲面质量、功能分区和装配细节，减少统一白色小板铺满的观感，使舱体表面、独立护罩与设备包具有不同尺度和高度。

**Architecture:** 沿用现有 `createMainRing()`、`createCore()`、Assembly、弧板生成器和资源释放。只调整两组的表面排布、局部护罩、材质及安装件；参数分别放入 `working.mainSurface` 与原 `working.coreDetail`，不新增子系统或跨组依赖。

**Tech Stack:** Three.js 0.180.0、原生 ES modules、现有 Vite 和离线素材捕获流程；无新增依赖、外部贴图或后处理。

**Spec:** 本文“调整设计”及“全局约束”。分区与构造基线见[鸟船设定第11节](../specs/2026-10-06-romantic-ring-station-design.md#11-固定主轴分区与外部构造r112026-10-08)，上轮成果见[R/11交接](../../design/torifune-ring-handoff.md)。

## 当前基线与问题

当前主工作目录包含R/09、R/10及尚未提交的R/11成果，应按实际工作目录建立基线，不能只从HEAD检出旧模型开始新一轮。保留现有变更和未跟踪预览；`.superdesign/`、`temp/`及其他任务的内容不纳入本轮。

生态环 `ringShielding()` 把每个舱段沿周向分成6列，内／外缘平面各4排，两侧平面各3排，圆角与连接区也使用同类细分板。主轴按16周向分区、约2–3 m轴向板长排布，上轮裁分后有697片覆板。两组大量使用相近灰白涂装和板缘纹理，板件大多贴壳，弱化了外挂支座、间隙和不同组件之间的高度差。

本轮恢复旧版外挂结构的可读层次，同时沿用新版的曲面、薄边、窄接缝、关闭接口及可靠安装关系。不回退模型文件，不删除上轮的收肩、检修槽或功能组件。

## 调整设计

### 1. 三种表面各有职责

| 表面 | 设定中的作用 | 外景表达 |
| --- | --- | --- |
| 舱体的连续外表面 | 覆护舱体的普通外包覆区域 | 大块、近壳、浅色；接缝较少，轮廓连贯 |
| 局部可拆护罩 | 遮护接合、维护和服务区域 | 独立边缘、局部灰色底层、安装座与可见间隙；有明确覆盖对象 |
| 外挂设备包 | 检查、分析、设备及能源服务组件 | 保留机箱厚度、底座和安装脚；体量高于普通护罩 |

灰白颜色仅定义涂装外观。实际板材、隔热层、碎片防护层和制造厚度继续保持未核定状态；本轮不把小板外观改称已设计完整的热防护瓦系统。可见灰色底层代表外包覆或接口基底，不表示舱体缺少防护或敞开内部。

### 2. 生态主环

- **普通区域扩大板块。** 每段周向6列改为3列，内／外缘平面4排改为2排，两侧平面3排改为2排。继续成形覆盖圆角，保留少量错缝和收尾片；过短端片并入相邻板，不机械保留半列碎片。
- **板块尺度来自现有壳体。** 普通内／外缘板轴向宽度约7 m，沿环长度因当地半径不同约5–6.2 m；侧板径向高度约3.5 m。它们是外景装配单元，可理解为内部另有分格的护板组件，不据此锁定一整块无加强薄板的制造方案。
- **接口护罩单独成组。** 16处接合区的外缘及外侧圆角保留分体护罩，减少罩上的细碎分格。外表面相对相邻普通板抬高约95 mm，露出窄灰色连接颈、独立罩边、支座和边缘阴影；不沿整圈增加第二层壳。
- **内缘和侧面分别处理。** 内缘普通板、接口板的法线外偏保持原值，避免进入R/10周向梁和入口净空。轴向侧面接合区仍露出端框和交叉杆，沿用浅覆盖，不套用外缘的抬高量。
- **已有服务节点整理盖板。** 普通节点可拆盖由3列整理为2列。四处大节点只整理两侧可用维护面，保留中央既有人员／物料设施占区；不增加节点盒体，也不为做大盖板封住中央通路。

主环保留当前灰白主色。灰色集中在接口基底、服务节点和压框；窄金属连接件继续克制，避免恢复整圈宽亮边。

### 3. 固定主轴

- **普通板面减少轴向分格。** 目标轴向板长从2.8 m改为4.0 m，按实际筒段长度收尾；周向仍保留16分区，避免破坏已核对的纵梁安装带与裁片关系。不同舱段不再使用同一密度的棋盘式拼板。
- **维护区露出灰色基底。** 以现有7处 `hatch` 为中心定义服务区，底层连续，外围普通灰白板绕开。服务区范围按盖板轴向长度加1.8 m、弧长宽度加1.4 m作为初始值，相邻同侧区域可合并；不得越过既有支座、接口和窗面。
- **增加少量独立罩板。** 7处检修盖外围采用较大的弧形护罩，初始外尺寸为原盖板轴向长度加1.1 m、弧长宽度加1.0 m；中央让出现有检修盖和压框，槽底、槽壁、铰座与把手保留。护罩与周围普通白板之间露出灰色底层，不在一块完整白板上再叠相同白板。
- **罩板架空，设备包保持更高。** 独立罩板底面相对当地舱壳外偏200 mm，渲染厚度25 mm；普通板仍为底面60 mm、厚度25 mm。罩边、短支脚和局部投影应能表达约115 mm的层间高度差。原机箱底部约310 mm及整体高度保持，不统一抬高设备包。
- **分区继续可读。** 人员舱保留安静大板面与两个小窗；检查转运与分析舱集中接口和维护面；设备舱依靠两个设备包形成轮廓；能源舱依靠配线盖与流体接头表达用途。连接颈和服务基底使用灰色，保留窄接环，避免五段全部变成同一种白色覆盖。

所有罩板以可用净空为边界。分析舱X=−15 m附近的检修盖邻近X=−16 m支环，扩大罩板时须裁切或缩小靠支环一侧；不得把支环埋进新罩，也不移动检修盖或支环来满足目标尺寸。其余服务区按同一原则处理。

### 4. 参数与材质

| 参数位置 | 字段／拟定值 | 用途 |
| --- | --- | --- |
| `working.mainSurface` | `circumferentialPanels: 3`、`axialRows: 2`、`sideRows: 2` | 普通主环板块的排布 |
| 同上 | `panelOffset: .065`、`panelThickness: .025`、`seam: .045` | 保留原普通板外偏、渲染厚度及板缝，单位米 |
| 同上 | `outerJointOffset: .16`、`outerJointThickness: .025` | 外缘／外侧圆角护罩沿名义壳轮廓法线外偏；普通板顶至罩顶相差.095 m |
| 同上 | `ordinaryNodeColumns: 2`、`majorCentreKeepoutHalfWidth: 4.55` | 服务节点盖板与大节点中央避让基线；实际已有设施占区优先 |
| `working.coreDetail` | `axialPanelLength: 4`、保留 `angularSegments: 16` | 主轴普通板轴向尺度 |
| 同上 | `shieldOffset: .20`、`shieldThickness: .025` | 主轴独立维护护罩 |
| 同上 | `shieldAxialPadding: .55`、`shieldArcPadding: .50` | 罩板每侧增量，单位米 |
| 同上 | `serviceAxialPadding: .90`、`serviceArcPadding: .70` | 灰色服务区域每侧增量，单位米 |

主环外缘接口罩的 `.16` 外偏以名义主壳轮廓为基准。其下连接颈比普通壳面低，真实支脚长度须从现有连接颈和端框表面到罩背计算，不能把 `.16` 直接当实际空气间隙。转角也须按实际轮廓法线定位。

灰白普通板与灰色基底使用不同材质职责。新增仅由主轴使用的 `coreBacking`：建议灰色0x748087、metalness约.25、roughness约.74，仅使用细颗粒纹理，不绘制板缘。弧形普通板继续使用 `coreHull`／`corePanel` 的UV1板缘，局部护罩可使用次级灰白。现有 `pressureHull` 等共享材质不修改。

保留UV0的2 m颗粒尺度与UV1的整板边缘映射，放大板块不会同步放大颗粒。通过尺寸、罩边和投影体现层次，颜色变化只辅助功能辨识。不上大面积锈蚀、强黑边或高反光金属。

## 全局约束

- 主环112／90 m名义压力壳尺寸、16舱段、四辐条、R/10内缘承力结构、两条人员通路保持。
- 主轴五段位置、总长、中央最大半径、R/11收肩、九处端部接合、半径2.8 m通道和原功能组件保持。
- 四条350 mm主轴纵梁、中心半径5.15 m、16支撑站、原8°安装带及R/11根部避让保持。
- 主轴新件只挂固定组，主环新件只挂主环旋转组；所有anchors、标记及转接舱归属保持。
- 副环、对接节点、推进、板翼、机械臂及其系统边界保持；允许同步本轮护罩的局部铰座、锁扣与短安装脚。
- 内缘贴壳梁、人员入口、轴承、能源挂点、RCS及轨道支脚的实际占区优先于拟定罩板尺寸。放不下先裁片或缩小本轮罩板。
- 所有罩板有实际安装接触；沿用曲面垫座避免理想圆面与真实网格之间悬空。保护壳体连续，维护孔不切穿压力壳。
- 重复几何继续缓存／实例化，缓存键须包含轮廓、半径、角宽、偏移、厚度及细分数，防止不同高度共用错误几何。
- 不改默认镜头、灯光、后处理、查看器交互和部署方式；不用改镜头或增亮来掩盖层次不足。
- 默认不新增永久测试；使用相关已有检查、必要一次性生产几何核对及截图。浏览器只加载与截图，不自动点击、填表或执行交互流程。
- 不自动提交、推送或部署；拟作为下一轮外观版本，版本号只在实施完成后更新。

## 外观验收标准

1. 固定的整站镜头下，生态环呈连续大板面，接口和服务区有少量独立罩；主轴的端部、服务基底、罩板与设备包仍能区分。
2. 同一位置的灰白板面、灰色底层和外挂罩边有可见遮挡与投影差异；局部加深罩边，普通表面不统一加厚。
3. 接缝密度下降，没有为了填满表面保留大量小碎片，也没有把纹理颗粒放大成瓦片花纹。
4. 护罩能看出覆盖对象和安装脚，底层连续；板件没有穿梁、遮住入口、埋入支环或悬空。
5. 副环、承力构造、功能分区、设备包、人员转接与运行分组沿用当前成果。

本计划中的尺寸为局部外景工作值。实施验证不包含真实板材工艺、热控、防碎片能力、载荷、承压、全船动态扫掠或低端真机性能验收。
