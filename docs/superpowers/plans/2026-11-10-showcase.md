# 展示模式实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 冻结当前排期，管理员独立维护每坑位一份三选一展示内容，手动公开。

**Architecture:** 复用现有 Worker、D1、私有 R2 和作品路由。新展示表为公开内容唯一来源，投稿档案保留原职责；排期冻结统一阻止真实业务写入口。

**Tech Stack:** React、TypeScript、Hono、D1、R2、react-markdown、remark-gfm。

**Spec:** `docs/superpowers/specs/2026-11-10-showcase-design.md`

## Global Constraints

- 一坑位一行，图片集／Markdown／B站三选一，仅管理员手动公开。
- 不新增展示版本库、恢复队列、后台任务、对象存储服务或独立数据库。
- 公开内容不得泄露投稿档案；审核或作者确认不能自动发布或覆盖展示资料。
- 继续特别作品可公开但特别席位不进入公共时间表的规则。
- 不执行浏览器自动点击、填表及交互E2E；仅必要截图和已有检查。
- 用户已明确“确认，开干”，本计划作为执行记录，不再次请求已给出的实施授权。原目录为非main开发分支，复用当前工作区，新建feature分支保护原分支；原有未跟踪素材不动。

## Review Focus

- 冻结时撤回报名、后台改资格也不能移除作者：任务1覆盖实际数据不变。
- 草稿预览图可见但正文图片不可见，撤下后正文也不可见：任务2路由用例。
- 审核通过和作者确认不自动公开：任务3更新原有行为用例。
- 公开后继续编辑仍校验正文，不能保存空白公开页：任务2数据用例。
- 历史外链作品及特别席位兼容：任务2、3复用已有集成用例。
