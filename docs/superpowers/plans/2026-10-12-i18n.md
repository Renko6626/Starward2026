# 中英文界面 Implementation Plan

> **For agentic workers:** Use the confirmed design and keep independent file ownership during parallel work. Run existing checks; add permanent tests only for new language behavior and preservation of user content.

**Goal:** 英文访客与作者可理解并完成现有公共浏览和作者流程，后台保持中文。

**Architecture:** 使用 i18next / react-i18next 管理浏览器文案，保留当前 URL。共用展示层和 Worker 提示适配层显式接受语言，兼容当前中文默认调用，不改变业务数据或认证接口。

**Tech Stack:** React 19, TypeScript, TanStack Router, Hono, Cloudflare Workers, i18next, react-i18next。

**Spec:** `docs/superpowers/specs/2026-10-12-i18n-design.md`

## Global Constraints

- 首批仅 zh-CN 与 en；后台保持中文。
- 不修改数据库、排期计算、认证方式、业务字段值或作者内容。
- 文案使用自然具体的英文；规则逐条对应，不改变约束。
- 用户已有未跟踪目录不属于本任务；工作在用户创建的 feat/i18n 分支内。
- 默认不新增文案与布局测试，浏览器仅截图，无自动交互。

## Review Focus

- 保存的语言优先于浏览器语言，未知语言回退中文。
- 管理员页面及 API 即使 Cookie 为英文仍保持中文。
- 语言切换保留未提交表单，既有用户内容不参与系统文案翻译。
- 英文 API 失败、成功和历史提示不遗漏中文系统模板。
- 英文邮件、条款及北京时间说明与网页语言一致。

## Implementation evidence

- Implemented on `feat/i18n`, retaining the original untracked directories. No database migrations, admin page edits or deployment. The user subsequently authorized copy revisions, committing and pushing the feature branch.
- Language preference initializes before the first render; explicit email/policy language links save the preference. Shared components use a fixed Chinese instance on admin pages. Application and auth requests carry the selected language.
- Server messages live in `src/shared/locales/server.ts` so retained client notices can use the same explicit system-text adapter. Worker projection touches only documented system display fields. Authored work, profile, contact, swap messages and review notes remain opaque.
- Dynamic English history is generated from existing structured event payloads, preserving custom slot names containing prose separators. Anonymous labels are selected from the original anonymity flag, preserving an authored name even when it equals a Chinese system label.
- Schedule permissions use a request sequence and loaded language; mutation invalidates earlier reads. Language changes retain drafts and form refs.
- `npm run check`: passed.
- `npm run test`: passed (62 files, 326 tests). Existing negative-auth tests emit their expected diagnostic errors.
- `npm run build`: passed; Vite retains its bundle-size warning. No bundling refactor in this task.
- `git diff --check`: passed.
- Screenshot-only review: English desktop/mobile home and login, mobile participation guide, desktop rules and schedule, plus Chinese homepage. No horizontal overflow or page runtime errors; no browser clicks or form filling.
- Not verified: real email delivery or an end-to-end browser registration/submission workflow.
