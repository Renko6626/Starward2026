# Relay Publication Implementation Plan

> 执行方式：本会话直接实施。用户已明确要求开干，不重复请求设计或执行方式确认。

**Goal:** 开放作品字段编辑，并完成发布提醒、首次链接提交确认与审核通过后的自动公开。
**Architecture:** 沿用工作台、作品草稿与 D1 事务。新增独立首次确认时间，公开状态沿用 published_at；共享北京时间规则。
**Tech Stack:** React / TypeScript / Hono / Cloudflare D1。
**Spec:** ../specs/2026-10-10-relay-publication-design.md

## Global Constraints

- 无新依赖，不通知审查人员，不重置已通过审核，不新增作品版本副本。
- 首次链接提交即确认，修改链接保留首次确认时间；首次确认仅在北京时间发布当天。
- 不自动测试浏览器交互、不部署、不触及已有无关未跟踪目录。

## Review Focus

- 午夜与一周边界；页面跨日后权限更新。
- 换期或撤回发生在读取和提交之间，提交不得沿用过期权限。
- 已确认未审核作品在后续审核通过时公开；主催撤下后普通编辑不重新公开。
- 匿名署名与私有审查信息不能进入公开响应。
- 确认后的链接替换不得改变首次时间或清空链接。
