# 浪漫工业环形空间站设计说明

日期：2026-10-06  
状态：待用户审阅。  
范围：`experiments/station` 独立 Three.js 样稿，不接入正式网站。

## 目标

综合原作设定、科研站功能草案、A/19 结构样稿和早期外景探索，另起一个更具浪漫主义识别度的环形人造重力版本。新版本要让主环在首屏镜头中成为明确的视觉主体，同时让推进、燃料、桁架、RCS、机械臂、对接口和散热系统都看起来是有任务、有维护路径的设备，而不是装饰性零件。

这是艺术与空间关系样稿，不宣称压力、载荷、角动量、热控、推进性能或在轨运动学已经工程验证。所有尺寸继续作为构图工作值，并在 README 和查看器说明中标注。

## 设定来源与优先级

新目录是一个独立的构型支线。它不会把既有文档中“无大型旋转环、采用黑箱人工重力”的科研站基线改写成环形站，也不会把环体的外观占位升级成已确认的世界观事实。

设定优先级如下：

1. **原作约束**：鸟船服务于地球环境改造的封闭生态实验；事故后仍保有自主转移能力；内部有森林、流水、动物、神社和不稳定人工重力。
2. **科研站功能基线**：D 对接与货运、H 人员支持、M 维护与取样、Q 隔离、N 生态分配、E-A 林地、E-B 湿地、R 循环、G 重力设备、T 主结构、W 能源热控、P 推进与安全飞控，以及 A-F 分阶段装配关系。
3. **A/19 工业实现约定**：X/Y/Z 坐标、开放推进架、模块连接痕迹、设备托盘、双机械臂、对接口和板翼/散热器轴向。
4. **环形支线的艺术选择**：主环承担机械旋转的人造重力视觉叙事，副环用于配平和维护叙事；这一层只对新样稿有效。

环形支线仍保留黑箱重力设备作为生态系统的科研/应急子系统占位：它可以解释环体低速、局部或不稳定的重力补偿，但不替代主环的旋转构型，也不赋予免费能源或无限作用范围。

## 设计基线

### 继承的现实锚点

- 坐标沿用现有约定：X 为主推进/服务轴，Y 为上下，Z 为站体两侧。
- 主结构由带节点板、套接件和斜撑的开放桁架组成，设备通过明确安装座接入。
- 推进采用双主发动机、四个外露燃料罐和小型 RCS 的视觉占位；不为模型编造燃料配比、推力或比冲。
- 前向人员接口、侧向货运/检查接口分工保留；货物先进入检查/暂存设备，再进入站内服务通路。
- 保留两支机械臂的分工：运输装配臂服务货运和设备转接，检修臂服务环体外侧与散热/能源设备。新版本静态展示工作姿态，不实现完整逆运动学。
- 光伏翼面和散热板继续作为独立能源/热控系统表达；散热器沿 X 方向形成明确的侧向板面和集流管路，避免与推进喷流重叠。
- 对接环、法兰、锁紧件、短过渡节、检查口和跨接口管线必须区分永久装配连接、人员通道和来访飞船接口。
- 主生态空间不是简单的“整圈房间”：参考既有截面试算，局部净高工作范围为 5–10 米，当前比较值为 8 米；10 米是候选内径，地面弦宽约 8 米，两侧各留约 0.8 米通路，中央植被包络约 5 米，基质层约 0.85 米，底部最深处约 2 米。新环只把这些作为模块内部的尺度参考，不把整圈外壳直接解释为可种植连续表面。
- 林地和湿地是同一主生态系统的功能分区，不直接称为互相独立的对照组；局部对照实验使用密封容器，实验流体不绕行人员生活区。
- 站体应表现分阶段建设和后期停用后的轻微年代差、面板替换和标识退色，但不擅自加入大面积锈蚀、爆炸损伤或已定论的事故原因。

### 新的环形构型

- **主环**：几十米级的分段式居住/生态环，先以约 46 米外径作为构图工作值，沿 YZ 平面旋转，环面分为 24 个可辨识模块；每个模块包含外壳段、窗口/遮阳片、服务脊和局部灯带。主环是画面主体，不做完整发光霓虹轮廓。外径、模块数和生态净高之间的关系仍需以截图检查为准。
- **副环**：约为主环半径一半的共轴服务环，位于 X 轴前侧并反向慢速旋转。它承载设备配重包、检修节点和惯量配平标记；副环的反向运动只作为角动量叙事和视觉提示，不宣称完成严格角动量计算。
- **中心枢纽**：固定的轴向核心、三组径向承力臂和两道旋转接口。核心集成导航、隔离、人员通道和环体供电/流体旋转接头的黑箱占位；旋转接头不做透明魔法效果，使用可见轴承壳、滑环盒和维护盖表达。
- **核心功能拓扑**：D/H/M 位于固定核心和前侧服务节点，Q/N 位于环体进入生态区前的隔离/分配边界，R 与 G-A/B 位于可抽取的侧向设备层；E-A 林地和 E-B 湿地沿主环分区布置，保留各自的关断、检修和取样方向。
- **工业尾段**：沿 +X 方向收窄为推进与服务桁架，四个燃料罐成上下两层布置，双钟形主喷嘴挂在开放推力框后端，阀组、增压瓶和隔热屏可见但不拥挤。
- **能源/热控支臂**：两侧桁架分别承接光伏翼和散热板，支臂、根部转轴、电气托盘、集流管与局部隔热片可见。板面保持与现有设计一致的轴向逻辑，不把散热板当成装饰翅膀。
- **作业系统**：一条外侧维护轨道连接主环服务节点；运输臂停在货运接口附近，检修臂在副环/散热器一侧展示伸展姿态，并保留一个空闲转接基座。
- **通信与对接**：前端 +X 侧设置抬高的主通信天线；−X 侧设置载人捕获接口；+Z 侧设置货运接口。三者使用不同颜色和结构语言，避免所有环都看起来像对接口。
- **尺度锚点**：继续把约 7.2 米的主天线、双侧约 12×24 米的光伏工作包络、双侧约 8×10 米的散热器工作包络、四个直径约 4.6 米/直筒段约 5.6 米的燃料罐作为视觉参考；它们不是新版本的性能、质量或运载承诺，必要时可为环体构图缩放并在说明中注明。

## 功能与装配叙事

新版本将既有 A-F 装配阶段折叠成可在外景中读到的分批建设痕迹：固定核心、基础飞控和最小能源先形成；随后安装人员/维护与隔离节点、环体桁架和机械臂；再挂接空载生态模块与 G 设备；最后补上循环处理、热控扩容、生态投入与长期科研设备。环体的不同面板、接口年代和空安装位用于表达这种历史，不把每个模块强行解释成一次发射。

主环内部不做完整室内场景，但外壳的窗口、遮阳片、取样口、服务脊、局部工作灯和 R/G 设备盒应让观者知道环内不是纯住宅旋转轮。原作中的森林、水体、动物与神社作为内部设定保留在外观叙事层，不在本轮建模为可见室内资产。

## 模块边界

`station-ring.js` 暴露 `createRingStation()`，返回 `{ object, markers, envelopes, update(time) }`，与现有查看器契约保持一致。

内部按以下函数组织：

1. `createMainRing()`：主环段、端部连接环、窗口/遮阳片、服务脊、局部灯带。
2. `createCounterRing()`：副环、设备配重包、维护节点、反向旋转挂载组。
3. `createHubAndSpokes()`：中心枢纽、旋转接口、径向桁架、固定核心设备。
4. `createPropulsionModule()`：燃料罐、开放推进架、阀组、增压瓶、隔热屏、主喷嘴和 RCS 喷嘴簇。
5. `createDockingAndRobotics()`：载人接口、货运接口、两支机械臂、空闲转接基座和抓取点。
6. `createEnergyAndThermal()`：光伏翼、散热板、根部机构、集流管和分散电气托盘。

重复杆件、窗口、紧固件和 RCS 喷嘴继续使用共享几何体与 `InstancedMesh`；环段只在需要不同材质或接口细节的位置拆分，以控制绘制调用。

## 动画、查看器与可访问性

- 主环和副环以不同方向、不同低速旋转；暂停、减少动态效果和页面隐藏时停止动画。
- 初始镜头保持现有侧前方构图，确保主环、副环、推进尾段和能源支臂同时可读；移动端通过更远镜头和更低 DPR 降级。
- 保留拖动、缩放、方向键、重置、纯净画面和操作包络按钮。包络至少显示载人对接、货运接近、机械臂工作区、散热器展开区和推进喷流避让区。
- 标签以“主环 / 副环 / 枢纽 / P 推进 / RCS / D 人员对接 / C 货运 / W 能源热控 / M 机械臂”这类功能名为主，避免虚构工程编号。
- WebGL 画布提供中文 `aria-label`；构建失败、上下文丢失和恢复继续沿用现有提示。

## 材质与视觉语言

沿用现有本地程序化材质体系：冷灰结构金属、暖色燃料罐、灰蓝服务面板、浅色散热面、深色玻璃和少量金色识别件。主环使用连续但不均匀的暖白窗口节奏，副环使用更冷、更稀疏的服务灯，中心枢纽和 RCS 使用低亮度琥珀提示。光伏翼保持深色电池片和边框/铰链层次，散热器保持浅色辐射面、背部加强件、集流管和根部设备盒的差异。辉光只用于灯带、喷嘴余辉和少量信标，禁止把轮廓全变成发光线。

空间背景、地球、月球、主光/反射光、阴影、ACES 色调映射与后处理沿用现有 `space.js` / `materials.js` 的策略；复制后只做适配，不修改已归档版本。

按项目约定进行桌面和手机截图检查，查看主环/副环遮挡、推进喷流、散热板和机械臂可读性；不自动点击按钮或执行完整交互流程。未验证的工程事项明确写入 README：角动量抵消、质量/质心、承压、结构载荷、热负荷、推进性能、机械臂碰撞和旋转接头寿命。

## 不在本轮范围内

- 接入正式首页或替换 `StarChart`。
- 建立真实物理旋转重力、质量/质心或轨道仿真。
- 完整机械臂逆运动学、碰撞检测、对接轨迹和展开扫掠。
- 生态舱内部植被、循环系统和人员活动场景。
- 重新决定鸟船原作点位（L1–L5）、具体推进剂、人员规模、生态物种、功率/热预算、运载路线或事故原因。
- 外部图片、在线纹理或新的运行时服务。
