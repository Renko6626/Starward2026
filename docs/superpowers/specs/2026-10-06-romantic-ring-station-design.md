## 1. 设计方法与本稿状态

从科研任务出发，逐步推导功能组成、模块职责、连接关系、结构构型和装配维护方式，最后进入尺寸、外观和 Three.js 建模。每轮只讨论一个主要问题，记录用户选择及其影响；发现冲突时回看相关决策。

用户进一步明确设计粒度：这是艺术风格空间站，功能细节应支撑外景中的模块、连接与使用历史。人员运行参数此前讨论过细，后续优先讨论影响整体轮廓、可读构件和模块接口的事项。人员支持先保留已确认的规模与驻留工作值，不继续展开人员编制、进站频率、消耗定额或完整任务排程；只有具体构件或空间方案需要时才补相应依据。

此前同路径草案由本稿整体替代，旧文本可从 Git 历史查阅。此前给出的 46 米外径、24 段环体、副环半径减半、三组辐条、双发动机、四个贮箱及具体布局均撤回为未确认项。代码目录方案和模型函数划分也不作为已批准架构沿用。

功能单元不等同于独立压力舱、环段、发射载荷或代码模块。物理模块与代码模块须在功能关系清楚后分别划分。

| 主环径向连接 | 四组开放桁架辐条，随主环旋转，经旋转端枢纽接入固定轴线核心；主环形成四处主要结构/服务连接节点（Q22 选择 A） |
| 主环周向承力 | 保留环形桁架的承力职责，压力舱通过安装座接入，辐条连接加强节点（Q23）；桁架与舱段交错整合在同一环体中，避免形成桁架内圈与铺在外侧的舱段外圈（Q24 用户修正） |
| 装配与工业表达 | 主环与桁架在轨组装，工业感来自分段连接、节点板、安装座、抓取点和跨接口服务连接等可读装配关系（Q22 用户补充）；具体装配路线与工艺待定 |
| 主环分段节奏 | 中等长度舱段与更多中小结构/设备节点交错，四个辐条接入节点较大，其余节点形成次级层次；避免完整光滑大圈的外观（Q25 选择 B） |
| 艺术方向 | 浪漫主义与现实主义结合，环形轮廓与工业设备共同构成视觉语言 |
| 保留的设备种类 | 推进器、燃料罐、桁架、RCS、机械臂、对接口、散热板；须有用途、连接与维护关系 |
| 旧版处理意图 | 归档写实版本，借鉴设计经验和构件，另建新目录 |
| 设计粒度 | 先讨论结构草案与模块组成，补全功能，逐个问题澄清后再落实模型 |

主环以生态科研任务为中心。生态空间、主要循环设备及主环骨架属于主环旋转组；副环具有独立的反向旋转结构；主分析实验室、人员支持、对接、主推进与大型板翼属于固定核心组。各组之间的转接接口仍须分别设计。

## 6. 每个物理模块的设计粒度

模块确定后，逐一说明：

1. 任务与使用者：为何存在，谁进入或操作，是否无人运行。
2. 内容与空间：设备、生物/流体、活动空间、服务层和防护边界。
3. 输入与输出：人员、货物、样品、介质、能源、热与数据的来源和去向。
4. 运行状态：正常运行、调试、隔离、维护及停用时的状态。
5. 接口与安装：压力、结构、流体、电力、数据和旋转接口分别如何连接。
6. 维修与装配：设备怎样到位、抽取、搬运、暂存与换装。
7. 故障影响：哪些局限于模块内，哪些影响邻接模块或整站。
8. 尺度依据与外观：尺寸依赖哪些任务量，外景应看出哪些功能和安装痕迹。

#### 该尺度下的量级参考

按 a = ω²r，若仅作算例把生态地面半径取为 48 米，0.16 g 对应约 1.727 rpm、34.75 秒一圈。若净高为径向 8 米，舱顶半径为 40 米，对应约 0.133 g，较地面低约 16.7%。这是有明确假设的几何计算，不是已确认的地面位置、转速或生态适应性结论。更大半径在相同地面重力下允许更低转速，并在相同净高下降低相对重力梯度；整体结构、质量、装配与配平仍需单独设计。

依据：[NASA 旋转重力关系](https://ntrs.nasa.gov/api/citations/20205005149/downloads/Artificial%20Gravity%20Student%20Presentation.pptx.pdf)。基质、防护和服务结构的厚度尚无设计依据，不能为了得到 48 米地面半径而反向固定为 2 米。

#### 需要展开的工程取舍

以下是后续讨论事项，尚未批准具体技术路线：

- **结构与分段装配**：分别说明环体周向承力、径向连接、压力舱安装与段间接口；制定未闭环、闭环、投入水与基质、旋转调试等阶段的载荷和配平状态。材料、舱段数量、辐条数量、连接工艺与发射件划分均待讨论。
- **截面与服务空间**：把净高、基质、水体、侧向/底部服务带、压力壳与防护逐项计入。若限制总厚度，明确哪些空间压缩、迁移或局部加厚，以及因此付出的生态与维护代价。
- **固定/旋转服务接口**：比较循环设备随主环布置和固定核心集中布置的方案，追踪必须跨旋转边界的电力、数据、冷却与介质。轴承、驱动、密封、泄漏隔离和检修不能合并成一个未解释的旋转接头。
- **副环配平**：以主环、辐条及随环设备的总转动惯量为输入讨论副环半径、质量分布与转速。共轴近似下需比较 I主ω主 与 I副ω副，方向相反；反转本身不能证明抵消。副环半径一半、等质量时，薄环近似要求约四倍转速；该例仅解释取舍，不决定副环构型。
- **载荷与长期无人运行**：跟踪水、基质和设备更换对质量分布的影响，讨论调平、振动、低推力机动工况与必要的启停策略。旋转机构、供能和环境控制的维护及退化方式须接入 Q3 的无人阶段，具体失效链后续确认。

参考：[NASA 环形站系统与装配研究](https://ntrs.nasa.gov/api/citations/19910002472/downloads/19910002472.pdf)中的分段装配和反向转子惯量关系、[NASA 离心机转子轴承案例](https://ntrs.nasa.gov/citations/20140012694)。这些资料用于识别设计问题，不把其任务规模、材料或技术成熟度移植为本站结论。

## 9. 进入建模前的检查

相关任务与结构方案确认后，再落实归档路径、新代码目录、模型接口和首轮体块范围。检查功能是否有对应空间、各通路是否连续、旋转关系是否解释清楚、设备是否有安装与维护位置。

## 10. 首轮代码组织建议

推荐沿用现有独立 Three.js 0.180.0 / Vite 7.3.2 样稿方式。旧源文件完整移动到 experiments/station/archive/torifune-a19-axial-spine/，新版本位于 experiments/station/ring-romantic/，experiments/station/README.md 作为版本索引。旧稿保留独立包与查看器，两个版本的源文件不共享可变模型实现。
