# 主页鸟船场景与可复用更新流程

## 目标与确认状态

用户补充要求：experiment 后续还会修改，静态预览生成、主页接入与编译应形成可复用脚本和流程。

本文件将该补充落实为具体边界与依赖，用户已确认并要求开始实施。不部署，不修改活动后端或独立查看器功能。

## 视觉与页面行为

- 首屏铺满深空场景。桌面站体放大、偏右，文字放左下；手机单独安排镜头及文字区，保证双环可辨识、导航和参与入口可读。
- 地球、月球与稀疏星点形成远景，沿用现有程序化素材和冷暖金属光照。
- 标题以 STARWARD 2026 与秘封组创作接力为中心，简介简短具体。下方用留白、文字和细线承接活动介绍及三步参与流程。
- 移除主页现有 StarChart 使用；其他页面保持现有风格。公共页头仅在首页采用适配场景的布局和背景。
- 默认双环慢速运行，提供暂停入口。尊重 prefers-reduced-motion；静态状态无需持续渲染。页面隐藏或首屏不可见时暂停帧循环。
- 首页文字与链接独立于 WebGL。懒加载 3D 模块，加载前、加载失败及图形上下文丢失时显示静态预览。

## 模型与场景边界

唯一模型来源保留在 `experiments/station/ring-romantic/src/`。不复制模型、不移动归档、不建立新模型库。

主页场景适配器放在 `src/app/components/station/`，直接导入 R/06 的 `createRingStation()`、环境材质和空间背景函数。它负责主页专用镜头、灯光、容器尺寸、运动、可见性和资源释放，不导入独立查看器的 `main.js` 或 UI 样式。

React 组件负责静态图片、加载状态、暂停状态与挂载/卸载；Three.js 场景模块只在客户端异步加载。静态捕获入口使用同一场景适配器，固定时间为 0，采用同一套桌面/手机构图。

两处模型导入统一解析至 Three.js 0.180.0，避免根包与 experiment 各自安装后出现重复运行库。保留 experiment 原有独立开发和构建入口。

## 更新脚本

新增 `scripts/station-assets.mjs`，通过 npm scripts 暴露：

- `npm run station:assets`：构建临时捕获页，启动临时本地静态服务，打开两个固定尺寸的画面，等待场景首帧就绪，输出桌面/手机静态预览及清单，结束时关闭浏览器和服务。
- `npm run station:check`：核对输入指纹与图片是否存在；不启动浏览器、不改文件。过期时明确提示运行 `station:assets`。
- `npm run station:update`：依次生成预览并运行主站构建。

固定捕获尺寸：桌面 1600×1000，手机 780×1688（对应 390×844 的 2 倍画素）。输出采用 JPEG，明确编码质量；不新增图片压缩服务或独立优化框架。

正式产物位于 `public/station/`，包括两张背景预览和 `manifest.json`，一并纳入版本管理。清单记录捕获尺寸、模型与场景输入 SHA-256 指纹、Three.js 版本，不以生成时间作为有效性依据。

输入指纹覆盖 R/06 模型、材质与背景源码、主页场景适配器、捕获设置及相关依赖版本。修改主页文字不要求重新生成背景图。

生成过程先写临时产物；两张图均成功后才更新正式图片与清单。失败退出码非 0，保留现有正式图片。构建临时文件放在忽略目录，不把截图工具绝对机器路径写进仓库。

捕获通过独立 Vite 入口完成，不依赖 Cloudflare、数据库、账号或报名接口。只加载与截图，无按钮点击、表单填写或交互流程测试。

主站 `build` 加入轻量的 `station:check` 前置检查，缺失或过期时停止并提示更新命令。普通构建不自动拉起浏览器；开发者修改 experiment 后主动运行 `station:update`。开发模式仍直接使用最新模型源码。

## 依赖与方案取舍

建议根项目加入 `three@0.180.0`、匹配的 Three.js 类型作为开发依赖，以及 Playwright 作为截图开发依赖。浏览器仅供本地生成产物，生产页面不包含截图依赖。提供标准浏览器安装指令与可选 executablePath 配置，避免绑定本机缓存路径。

推荐直接复用程序化模型源码：几何、贴图和双环动画无需另一套同步方式，Vite 负责正式编译和压缩。3D 模块与首页文本分包，限制像素比，复用模型现有实例化。

暂不增加 GLB 导出、网格简化、纹理压缩或新后处理。GLB 会增加中间模型产物及动画/挂点复接维护成本；若实际构建或渲染数据证明需要，再提交具体优化方案。

## 文件职责

- `src/app/pages/HomePage.tsx`：新首页内容与状态入口。
- `src/app/components/station/`：React 场景容器、主页场景适配器和场景配置。

- `scripts/station-assets.mjs` 与捕获入口：生成、检查及本地服务生命周期。
- `public/station/`：可部署的静态预览与输入清单。
- `package.json`、锁文件与必要 Vite/类型配置：依赖、命令和一致的模块解析。
- `docs/development/station-homepage.md`：修改模型后的更新命令、产物说明与失败处理。
