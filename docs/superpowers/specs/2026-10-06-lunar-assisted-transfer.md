# 本地计算月球辅助转移

用户已确认：Python + SciPy，地月平面 CR3BP；允许月球附近机动，由本地计算生成轨迹数据和主页白色 SVG 图，不再描论文图片。保留英文图示标签、辅助线、场景原色，公式暂不显示。只做截图，不自动交互，不部署。

## 模型与工作参数

- 地月在圆轨道上绕质心运动；飞行器视为无质量质点。单位归一化，地月共转平面坐标；太阳摄动、倾角、真实星历与推力持续时间不纳入。
- 默认 200 km 地球圆形停泊轨道、近月高度至少 100 km；抵达理想 L4 后匹配共转速度为零。
- 两段真实数值积分的滑行弧，三个可报告的脉冲：地球离轨、近月有动力借力、L4 抵达匹配。机动位置来自解，速度不连续、位置连续。仅绘制经过验证的可行解，不宣称全球最优。
- 论文 DOI 10.1016/j.asr.2021.10.025 的模型参数、相位与量级用于初值参考；本例的终端是理想 L4，而论文是非线性短周期轨道，结果不得混称为论文复现。

## 实现边界

`scripts/orbit-transfer/` 包含模型/积分、求解与校验、导出入口及默认配置；Python 依赖独立记录，不进入生产网站。SciPy 负责积分与非线性校正，Matplotlib 输出独立检查图。

`npm run orbit:generate` 求解、验证并输出轨迹 JSON、SVG 预览和验证报告；`npm run orbit:check` 只核对已生成数据的输入指纹与数值验收。常规网站构建不求解。主页将 JSON 的真实点列等比映射为 SVG，机动点绑定同一状态，不新增手画弧线。输出失败保留此前数据。

## 验收

- 滑行段 Jacobi 常量漂移、地球/月球碰撞与最低近月高度。
- 月球接近节点为近月点；段间位置一致，机动符合状态速度差。
- 终端位置误差与匹配后的共转速度；更严格容差独立再积分检查终点。
- 保存参数、求解状态与完整状态/时间点，数值可复跑。未通过上述检查不得发布生成数据。
- 永久测试只覆盖 L4 平衡、滑行守恒与不合格轨迹拒绝等关键不变量。运行相关现有检查和截图。
