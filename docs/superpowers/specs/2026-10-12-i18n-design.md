# 中英文界面

## 已确认范围

采用 i18next 与 react-i18next，在现有 React / TanStack Router / Cloudflare Worker 中实现简体中文与英文。公共站点、作者登录、报名、排期、作品投稿、历史记录、验证码邮件、活动规则及独立服务条款和隐私政策均提供英文。管理员页面与管理员 API 保持中文，不调整数据存储、认证方式或现有路由。

## 行为与边界

- 导航提供中文 / English 切换，同源 Cookie 保存显式选择；首次访问参考浏览器语言，未支持语言回退中文。服务器读取显式选择及 Accept-Language；英文邮件沿用发送验证码请求的语言。
- 前端语言实例负责页面文案，Worker 使用每请求的明确语言参数。禁止服务器修改全局语言实例。
- 字典按公共页面、账号入口、作者工作台、共用文案和规则划分；采用稳定语义键及中英文成对资源。
- 现有共用领域标签和服务端 message 保持中文默认值，以兼容后台及已有调用。使用明确的展示适配层把已知系统提示译成英文；不递归翻译任意业务字符串。后端错误码、成功状态、字段校验和事件 payload 不改变。
- 作者署名、标题、简介、标签、联系方式、管理员反馈、自定义时段名称保留原文。系统默认时段名称可以依据原始编号显示英文。
- 活动显示时区保持 Asia/Shanghai / UTC+8。语言改变显示格式，不改变排期计算、分组键或截止时间。操作时间维持当前浏览器时区。
- 活动规则中英文对应同一版本。独立条款继续支持直接 HTTP 阅读，并依据语言选择展示文档。
- 共用组件进入管理员路由时固定中文，不改变管理员页面文件。

## 验证

运行项目已有类型检查、相关测试和构建。仅为语言选择、服务端展示边界、邮件语言及管理员保持中文等关键新增行为补充简短行为测试。UI 只查看桌面及手机截图，不自动点击或填写表单。
