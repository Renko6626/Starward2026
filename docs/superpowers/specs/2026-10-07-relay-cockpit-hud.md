# 接力目录页：转移飞行器座舱 HUD

> 2026-10-07 保存状态：用户对首轮原型 C / 01 不满意，要求保存并结束。本文件保留讨论记录；当前原型未采纳，不继续实施或集成。

## 已确认的设计方向

用户选择转移飞行器接近空间站的舱内第一人称视角。视觉延续首页有考据、有工程细节的科幻工业风格。目录仍承担查看接力排期、寻找作者和作品的用途。

## 已确认技术路线

沿用 React、现有 Three.js 0.180.0 与原生 CSS。座舱结构与窗外空间站由一个页面专用 WebGL 场景渲染；HUD 时间表使用 HTML 叠放在其前方。复用现有 createRingStation 模型及适用的星空、天体和材质资源，新增座舱几何与独立取景，不扩展首页场景的配置接口，不改首页相机。

备选为预渲染座舱背景加 HTML HUD：运行成本较低，构图固定，但失去实时空间站旋转、光照和随屏幕比例调整的空间构图。推荐实时路线以延续首页的实体模型质量；静态降级图由同一场景生成。

## 构图和艺术内容

- 固定第一人称观察位置，机体框架位于画面两侧与底部。窗外空间站偏右上，中心保留时间表阅读空间。场景表达接近中的观察位置，首版不模拟真实交会制导和持续飞行。
- 座舱首版是近未来工程概念：有厚度的窗框、多层密封边、结构连接件、紧固件、仪表遮光罩和局部线束护罩。构件有明确连接关系，不宣称飞行器经过工程验证。
- 舱内以深灰金属、浅灰标记和局部弱仪表光为主；窗外沿用空间站实体细节与适用的太阳照明。玻璃反光克制，不能形成覆盖正文的亮斑。
- 接力目录是舱内透明任务显示的内容。保持桌面按行阅读的双栏顺序、手机单栏、日期分组、搜索、当前接力定位与作品链接行为。标题和时间为主要阅读层级。
- 航天背景标记仅显示有依据的目标名称和方位辅助符号。接力棒次和活动时间保持活动语义，不伪装为测得的距离、速度或燃料数据。
- 手机收窄窗框、简化边缘仪表并重取景，保留可见空间站及足够正文宽度。

## 模块与依赖边界

- 页面专用 React 背景组件负责延迟加载、就绪状态、暂停入口与降级图。
- 座舱几何模块仅负责创建结构与材质；场景模块负责相机、照明、复用空间站、尺寸更新、动画和资源释放。页面场景依赖模型，模型不依赖目录数据。
- WorksPage 继续读取 /api/works 并呈现 HTML 目录；装饰场景不读取业务接口，不干预搜索、链接和滚动。
- SiteLayout 仅为目录路由添加必要的全宽布局样式标记；其余公共页面布局保持现有行为。
- 不新增依赖，不修改接口、数据库、空间站模型设定或轨道求解模型。

## 动态与降级

空间站沿用既有旋转，首版观察相机固定。背景不捕获指针事件。支持暂停和系统减少动态偏好；页面隐藏时停止动画。限制像素比、手机降低渲染成本；卸载释放动画、观察器、GPU 资源与事件监听。加载失败或 WebGL 不可用显示同构图静态背景，目录始终可以独立呈现。

## 验收

先检查桌面、手机静态截图：座舱视点可辨认、工程结构连接合理、空间站可识别、列表和搜索清楚。运行相关已有静态检查、构建与项目要求的资产检查；不自动点击、填写或执行浏览器交互流程，不为纯视觉改动新增永久测试。不推送或部署。
