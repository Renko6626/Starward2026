# Documentation Index

## Purpose

本文作为 `docs/` 目录入口，说明文档分层结构与推荐阅读顺序。

## Directory Structure

```text
docs/
├── README.md
├── architecture/
├── development/
├── delivery/
├── product/
└── design/
```

目录职责如下：

- `architecture/`
  - 长期稳定的系统架构、领域模型与命名规则
- `development/`
  - 本地开发、seed、调试与运行约定
- `delivery/`
  - 交付阶段、范围定义与实施计划
- `product/`
  - 稳定的产品流程、账号模型与页面职责
- `design/`
  - 页面线框、内容结构与模块规范
