# Starward2026 Homepage Wireframe

Last updated: 2026-04-11

## 1. Purpose

本文定义首页的线框、信息层级与视觉方向。

## 2. Design Brief

首页承担以下职责：

- 说明活动主题
- 展示当前阶段
- 提供主要入口
- 建立接力与档案的视觉语义

## 3. Visual System

### 3.1 Core Direction

建议视觉方向：

- 档案式特设站
- 接力进度看板
- 夜间观测主题

### 3.2 Typography

建议字体组合：

- 标题：`Noto Serif JP`
- 正文：`Noto Sans JP`
- 数字与编号：等宽或近等宽字体

### 3.3 Color

建议色彩基调：

- 深夜蓝黑
- 暗红或棕红
- 纸页米白
- 金属灰
- 低饱和青色点缀

### 3.4 Motion

动效应仅用于以下场景：

- 首屏入场
- 接力节点高亮
- CTA 状态切换

## 4. Desktop Wireframe

### 4.1 Global Header

页头应包含：

- 活动名称
- 主导航
- 当前阶段标签
- 联系入口

### 4.2 Hero

首屏应包含：

- 活动标题
- 副标题
- 当前阶段
- 主 CTA
- 次 CTA
- 关键日期或状态条

### 4.3 Event Intro

说明区应包含：

- 活动简介
- 参与方式概述
- 发布方式概述

### 4.4 Relay Mechanism

机制说明区应包含：

- 接力规则摘要
- 时间段与流程说明
- 参与角色说明

### 4.5 Relay Board

接力看板应包含：

- 当前进度摘要
- 节点列表或可视化顺序
- 当前高亮节点

### 4.6 Timeline

时间线应包含：

- 报名阶段
- 创作阶段
- 发布阶段
- 归档阶段

### 4.7 Participation Notes

参与须知区应包含：

- 报名资格说明
- 主要规则摘要
- 常见问题入口

### 4.8 Archive Preview

归档预览区应包含：

- 已发布作品占位
- 后续公开说明
- 作品入口占位

### 4.9 Contact and Footer

页脚应包含：

- 主催信息
- 联系方式
- 版权说明

## 5. Mobile Wireframe

移动端顺序建议如下：

1. Hero
2. 当前阶段
3. 活动简介
4. 接力看板
5. 时间线
6. 参与须知
7. 归档预览
8. 联系方式

## 6. Stage Variants

### 6.1 Recruiting

主要 CTA：

- `参加接力`
- `查看规则`

### 6.2 In Progress

主要 CTA：

- `参与者入口`
- `查看当前进度`

### 6.3 Public Release

主要 CTA：

- `浏览作品`
- `查看活动说明`

## 7. Copy Rules

首页文案应满足以下要求：

- 使用说明性表达
- 统一使用阶段术语
- 不使用临时占位语气
- 不使用后台系统术语

## 8. Implementation Notes

首页实现时应注意：

- 模块顺序应支持阶段切换
- 首屏信息应在 5 秒内可辨识
- 重要状态信息不依赖动效表达
