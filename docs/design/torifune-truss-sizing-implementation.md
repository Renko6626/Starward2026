# 鸟船中档杆件方案实施计划

> 执行方式：本会话直接实施，使用 executing-plans 与 threejs-geometry；已有方案已获用户确认。遵守用户“不重复确认已确认路线”及几何改动不默认新增永久测试的约定。

**目标：** 将已确认的中档杆件外截面与必要支撑落实到共享模型，更新静态素材与交接。

**架构：** 沿用现有固定组、主环组、副环组及实例化装配；在现有 layout 参数中记录候选外宽/壁厚，不引入新的模型子系统、依赖或物理仿真。几何只表达外包络，壁厚用于研究记录，不据网格体积宣称真实金属质量。

**技术栈：** 当前 Three.js、Vite、原生 ES modules。

**依据：** `torifune-truss-sizing-results.json`、本会话确认的中档尺寸表及 `torifune-ring-handoff.md`。

## 约束与检查重点

- 主环112 m、副环84 m；四副10×45 m光伏翼、四副6×40 m散热器及方向保留。
- 固定/旋转边界、人员转接、压力通路、机械臂与推进布局保留；不把外部杆件当承压壳。
- 主轴直线斜撑会穿舱，用户需选择具体约束路线；等待期间其他部件可独立实施。
- 检查杆端连接、框架四面支撑、散热背架段间连续性、重载横梁连接和远近景比例。
- 默认仅页面加载和截图，无自动按钮点击、表单或交互流程。
