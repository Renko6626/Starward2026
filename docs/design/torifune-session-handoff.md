## 当前已确认的基线

- 科研站以封闭生态系统研究为主，近未来地月技术水平，后期停用；人工重力采用虚构黑箱技术，撤回大旋转环。原作没有规定当前工程外形。
- 沿用 A 的纵向顺序与错位生态舱。用户在 A / 18 后选择第二种调整路线：骨架靠近主要承力节点，生态舱通过端部环侧接。A / 19 已据此撤下低位贯通底架；这不是历史 B 分叉方案。地球、月球和空间站继续共同出现。
- 主推进采用可储存双组元化学方向，双主发动机、四个大贮箱和姿控喷嘴是当前外形占位；燃料、供给循环、性能和储备未确定。
- 人员对接口在前端，货运接口位于服务组侧面；货物先检查暂存，经服务组和隔离节点进入生态区。
- 两支机械臂：下方移动底座运输装配臂、湿地外侧检修臂。保留双端抓取与转接基座的方案；没有采纳两支臂永久固定在各自轨道的新提案。灰蓝运输臂朝货运侧，浅色检修臂位于舱外。
- 主天线是通信模块视觉重点，传感器是少量次要小件。主天线开口朝场景地球，抬高支柱留出舱体间隙。
- 生态舱采用局部观察窗，内部简化林木、水面与湿地植被用于功能辨识；外壳大部分保持实体防护板。
- 能源桁架采用箱形空间桁架，设备方案为分散侧挂托盘。大棕色柜体已撤下，不再恢复。
- **坐标约定：X 为主梁/推进轴，Y 为上下，Z 为主梁两侧。太阳能板面位于 XZ，法线朝 Y；散热板面位于 YZ，法线沿 X（当前正面 −X，反面 +X）。** 这是用户明确要求，后续不能仅按“互相垂直”任意转轴。
- 保留独立 Three.js 工作方式，不生成 GPT 图片，不修改正式网站主体。

## A / 19 纵向骨架与侧接舱段

用户已确认采用第二种路线，沿原 A 构型调整结构连接。见 [侧视和端向关系图](./torifune-axial-spine.svg)。

- 服务/通道段骨架在压力通路外围：X −24 至 16，纵梁中心位于 Z ±2.75、Y −3.8 / 1.3。货运、林地与湿地支路所在侧面留开口；循环舱下方的顶面构件避开原 R 体块。
- 两座生态舱的位置和窗口方向沿用，在林地 X −6.7 / 5.7、湿地 X 6.3 / 13.7 设置候选端部承力环，通过内侧短支杆连接骨架；撤掉舱底的横向长托架。环表示需要后续设计的加强接口，不能直接把防护板当承力压力壳。
- X 16 至 18 收窄过渡，后段骨架至 X 34.4，纵梁 Z ±0.55；四个贮箱通过环上内侧安装点接到窄骨架。原推进底部网格与 V 形落地式支座撤下，独立设备托盘保留并改挂骨架。
- 发动机位置沿用；推力框接到后段骨架。隔热屏前移至 X 33 并分左右两片，中部为骨架留空；设备箱及供给管路同步让位，发动机供给管从屏下通过。
- 运输轨道 Y −9.5 上移至 −5.2，运输臂及底座同步调整。外侧检修基座改接生态舱端环，林地/湿地基座分别位于 X −6.7 / 6.3、Z −15.9 / 15.9，基座上表面附近 Y −2.9；检修臂保持原两段长度，整体迁移到新基座。候选作业/停放包络与标签已更新。
- 天线、货运支承、姿控组件、能源支臂、散热支臂与设备托盘接回新骨架。太阳能翼与散热器的板面位置、尺寸和用户指定法线沿用。
- 当前骨架从 X −24 延伸至 34.4，共 58.4 米工作跨度；这是外观与连接关系研究，未建立质量、质心、惯量、强度或完整碰撞模型。机械臂换位路径仍待核对。

## A / 18 开放推进设备架

用户确认撤掉四个贮箱下方约 17×10.8×2.4 米的整块方盒占位。原有横向桁架通过新增纵梁、斜撑和下接主梁的短支柱组成开放设备架；贮箱 V 形支座接到上层纵梁，发动机推力框根部接到新增横梁。

供给干线从原来穿过支座横杆的位置移到横杆下方、V 形托架内侧，并接回现有阀组。两侧各设两个小设备托盘，附局部隔热挡片；发动机前方独立隔热屏保留。四个贮箱、发动机、光伏及散热器位置继续沿用。本轮明确开放支承与设备关系，未验证载荷、流体性能或完整碰撞包络。

## A / 17 桁架质感快速优化

按用户要求快速减轻塑料积木感：主桁架、生态舱支架及横向能源桁架采用带小倒角的方形金属杆件；使用独立银灰金属材质与较暗的连接件材质。主梁节点由厚方块改为薄连接板和紧固件，斜撑略收细并补端部套接外形。几何与材质继续共享并实例化，沿用原拓扑、安装位置及光伏/散热轴向。管路和机械臂仍使用各自材质。

这是截面、节点外观和反射的局部细化，未重新设计载荷、杆件壁厚或实际连接工艺。生态与循环套件继续暂缓。

## A / 16 材质与观察窗

用户选择先做近未来空间站材质与观察窗细化（评估建议 4、5），明确将生态区和循环套件延后。A / 16 沿现有布局完成：

- 浅色防护板增加薄边厚度、边缘折返、细小紧固件纹理和受控的表面差异；色块按带状组织，减少规则棋盘式交替。
- 区分哑光涂层、冷灰裸露金属与局部隔热毯；本地生成颜色、粗糙度、微表面及隔热褶皱纹理，隔热毯带包边和固定片。无外部纹理依赖。
- 观察窗增加凹入密封边、较深窗框、金属压框、紧固件与上侧收起的四片防护盖；原有窗口位置、尺寸和生态内部占位沿用。
- 窗旁已有检修盒补盖板、锁扣和把手。玻璃单独保留以按窗口排序；静态实例化按原投影/接影属性分组，避免重新开启玻璃投影。
- 防护盖仅表达静态外观，未验证折叠机构、扫掠或应急封闭；玻璃仍为透明度与反射的美术近似，没有多层折射或承压计算。

## 本次评估中保留的后续建议

- **生态科研辨识（暂缓，原建议 1）**：在可见区域补固定相机、环境传感器、取样点、种植槽边缘和照明设施；林地加强树冠/林下层次，湿地加强水岸和浅水区。设备集中于服务侧。两舱窗口同朝 +Z，林地窗口偏主梁侧；后续先比较静态视图，再决定是否调整开口，A / 16 未改朝向。
- **R 循环套件（暂缓，原建议 2）**：细化保温设备罩、泵阀检修箱、过滤单元抽取盖、取样接口及通向两生态舱的管线；处理设备保留受保护空间，外部表达维护面。林地与湿地仍是同一系统的功能分区，不能称为独立对照组。
- **可维护设备（原建议 3）**：在双机械臂服务范围内补可更换设备的抓取柄、锁紧和插接面，备件托盘、空安装位、定位标记、局部工作灯及有用途的系留/作业点。先补独立空闲换位基座，明确货物从舱内到舱外的路径；不默认机械臂全站可达。
- **视觉主次（原建议 6）**：后续细节优先投入科研和服务设备，避免继续放大发动机信息密度。推进段先在 A / 18 改成开放设备架，A / 19 进一步撤下底部网格、改接贮箱之间的窄骨架；主推进路线和已确认贮箱/发动机体量保持。
- **标识与使用历史（原建议 7）**：站名、舱段编号、设备编号分远中近三级；补抓取标记、检修方向及少量警示色。手机尺度优先保留窗口、成组设备与识别色块。先确定停用状态，再考虑更换面板色差、褪色标记、局部隔热毯变色、关闭的工作灯和维修补片，不擅自加入严重破损。

材质与观察窗（原建议 4、5）已落实为 A / 16，推进底座已在 A / 18 处理；其他待办仍保留。参考资料：[NASA 生命保障系统](https://www.nasa.gov/reference/environmental-control-and-life-support-systems-eclss/)、[NASA 外部备件平台](https://www.nasa.gov/international-space-station/external-stowage-platforms-1-3/)、[ESA Cupola 窗与防护](https://www.esa.int/Science_Exploration/Human_and_Robotic_Exploration/Node-3_Cupola/Cupola)。这些是功能和外观参考，不作为当前尺寸与工程性能的证明。
