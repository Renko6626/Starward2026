# 地面观测站样稿

当前采用空间变轨机动线图：中央的切向转移与升轨弧段、左上轨道面调整、左下交会相位椭圆。无背景文字、角度刻度或网格；天线地面网格已移除。

当前为构图与建模样稿：时间表居中，右侧一座大型偏置双反射面天线进入背景；任务行采用透明背景，轨道图保持可见。天线已进入首轮建模，整体轮廓仍待用户确认。

已确认的技术组合：Three.js 天线模型、SVG 轨道背景、HTML 时间表。此目录为独立视觉样稿，使用 24 位示例作者，不读取或修改生产排期。

从仓库根目录运行：

```sh
npm run dev --prefix experiments/ground-observatory
npm run build --prefix experiments/ground-observatory
```

开发预览（默认采用变轨机动方案）：

http://localhost:26108/

先前构图样稿：

- A 地面跟踪几何：http://localhost:26108/?diagram=tracking
- B 方位角与仰角：http://localhost:26108/?diagram=sky
- C 轨道平面与姿态：http://localhost:26108/?diagram=plane

三版使用同一天线、时间表和页面布局，仅替换中央 SVG。图形使用几何示意，不表示实际轨道预报。

- `antenna.js`：米制偏轴抛物面主碟、椭球副镜、背架、收窄支臂、双侧俯仰支架与方位轨道；重复构件使用实例化。
- `scene.js`：整体与页面使用地面侧后方透视相机，正背侧审查使用正交相机；包含实体材质照明、按容器尺寸绘制及 WebGL 资源释放。当前不运行持续动画。
- `orbit.js`：变轨机动与先前三个独立 SVG 几何构图，不复用首页转移图，也不改变项目轨道求解模型。
- `main.js`：使用 A 方案示例排期，提供选中、搜索、定位与手机详情。
- `style.css`：控制图形和文字的层次、桌面侧边构图与手机适配。

验证：样稿构建通过；检查三版 1440、390 像素宽截图，均无横向溢出和页面运行错误。未执行自动点击、输入或交互流程测试。

## 偏置天线首轮模型（2026-10-09）

定位为以射电观测为主、兼顾鸟船通信的虚构地面设施。用户选择偏置双反射面、40 米级巨构、宽基座与双侧俯仰支架、正面实面与背面复杂桁架、下伸副镜臂。

当前轮廓与展示：主碟采用宽 40 m、高 30 m 的椭圆投影边界，取消下缘收窄；母抛物面焦距 18 m。展示俯仰角 82°，中心面法线约向上 48°，保留偏置曲面的侧面深度。整体与页面相机位于地面约 1.7 m 高处，从侧后方仰视，以背架和双侧支撑为主要可见面。当前为供用户继续判断的外观草案，不记录为最终外观批准。

所有模型几何按 **1 单位 = 1 m** 构造，查看时仅调整相机，不放大局部构件。工作尺寸以 `antennaDimensions` 为准：

| 部位 | 当前工作值 |
| --- | --- |

| 副镜 | 6.6 m 直径的椭球曲面截片；位置由主焦点和接收相位中心推导 |

| 俯仰轴 | 高 27 m，当前展示姿态 82° |

## 工业结构细化（2026-10-09）

按用户确认的方案，折线桁架馈源臂改为两条沿连续三次贝塞尔路径收窄的空心箱梁；根部回接到主背架的实际环梁／径向节点。增加四道拼装接缝、侧面检修盖、带夹持件的外部线缆路径和末端六支副镜调节执行器。执行器下端落在直径 2.36 m、厚 35 mm 的安装盘上，盘背经四根短支座接入两条箱梁末端；六个安装脚均核对了与盘面的接触。沿用已有主、副反射面的光学位置，避免凭外观挪动焦点。

双侧支座主弦区分宽深，增加连接板；轴承座补外侧法兰、端盖和紧固件，两侧各有齿弧、驱动小轮、减速机、带散热筋的电机及检修平台。底部配置设备间、维护门、散热百叶、两组外置冷却设备、配电柜、线缆桥架和中心线缆过渡架；八组承重轮补轴端、轮缘、轮架与驱动包。主碟背部增加面板调节支座和扭矩汇集框的盖板／紧固件。外观表达按不同构件分配细节，没有均匀加密全模型桁架。

两条空心箱梁实际生产网格的封闭体积约 4.802 m³；若假设均为密度 7850 kg/m³ 的钢，其裸梁壳估算约 37.7 t。这个量级只用于暴露壁厚与质量的关系，不含横撑、接头、设备，也不是全臂实称质量或承载验证。普通支架仍只建外包络。

一次性检查直接读取生产网格：主碟边缘射线、副镜焦点、坐标有限性、地面与馈源臂局部避让沿用上述检查。设备间主体、屋顶和底座三组 OBB 对支架盒形实例的相交数为 0；允许各自设备内部的安装接触。六个执行器安装脚的底面与安装盘正面共面，最大平面误差约 1.7e-15 m，安装脚中心半径为 0.9 m，完整包络位于半径 1.18 m 的盘面内。该范围未覆盖全部机械件、动态扫掠或全站碰撞。

## 冷色夜景与星空（2026-10-09）

用户选择试用冷色夜景。整体透视查看页加入本地程序星空与暗色地面；星空固定在无限远背景，不对应真实星表。正交结构近景使用同色系暗底，避免单位天空盒在正交投影中不能铺满画面的问题。时间表背景继续透明合成，不铺设星空和地面。

主光采用冷色定向光，天空填充减弱，另有低强度轮廓光。主碟和构件启用投射／接收阴影，2048² PCFSoft 阴影图覆盖模型；模型和光源固定时缓存阴影，仅相机交互触发重绘。环境反射采用本地浮点天空辐射贴图经 PMREM 预过滤，与可见星空分开控制。环境强度 0.8、曝光 1.05 是本版美术工作值，不表示校准的月光照度。

材质按用途区分：主碟银灰反射面（金属度 0.82、粗糙度 0.38）；支架涂装表面（金属度 0.12、粗糙度 0.43）；端盖和紧固件裸金属（金属度 0.92、粗糙度 0.24）。深色支架、混凝土与线缆保持较粗糙，主碟分块色差收敛。模型尺寸、光学位置和杆件几何沿用。

卸载释放环境、星空与阴影贴图；WebGL 上下文恢复时从保留的 CPU 辐射像素重新生成 PMREM，避免恢复后丢失金属反射。该恢复分支仅作代码审查，未自动模拟上下文丢失。

`node --check experiments/ground-observatory/scene.js`、同目录 `antenna.js`，`npm run build --prefix experiments/ground-observatory`、`node temp/ground-observatory/audit-antenna.mjs`、`git diff --check`通过。整体、正背侧、三类近景和页面桌面／手机仅加载截图，页面／控制台无错误，无横向溢出。保留 Vite 大包提示；未自动拖动或执行交互流程，未验证低端真机性能，未提交、推送或部署。

网页嵌入视角调整：从侧面向主碟正面偏转约 18°，保留约 1.7 m 地面视点与右侧背景位置。可拖动整体查看器仍从侧后方打开。
