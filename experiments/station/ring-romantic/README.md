# 环形鸟船 R/12

地月 L4 的低重力生态实验站外景初稿。采用已确认的前侧副环布局，主生态环、反转副环和固定核心各自装配，两个轴心人员转接舱独立挂载。所有几何、表面纹理和地月背景均在本地生成，沿用 Three.js 0.180.0、Vite 7.3.2 与原生 ES modules。

## R/12 外表面层次

主环普通区域由6周向列／4内外缘排／3侧面排整理为3列／2排／2排，大板、成形圆角和局部接口罩分别表达；外缘接口罩底外偏160 mm，普通板和内缘仍为65 mm，渲染厚度25 mm。灰色连接颈、窄接环、安装脚与罩边保留。主环覆板和接口罩合计960片，外缘及外侧圆角抬高罩片128片；四处大节点盖板留中央轴向通路，并为既有横梁开400 mm切向安装槽。

主轴普通板目标轴向4 m，保留16周向分区和原根部避让，普通板604片；七处检修盖外围露出连续灰色基底，独立罩裁成27片，底外偏200 mm、厚25 mm，各片经两脚和曲面垫座接壳。现有窗口、检修槽、设备包及端部收肩保持，设备包高于护罩。原承力构造、运行分组、镜头、灯光和共享几何生成器保持，无新依赖。

职责、工作尺寸和材料边界见[设定第12节](../../../docs/superpowers/specs/2026-10-06-romantic-ring-station-design.md#12-舱体外包覆与外挂护罩r122026-10-08)。预览：[主环整体](./previews/main-ring.png)、[接口与大板](./previews/main-hull.png)、[主轴前部](./previews/core-detail.png)、[主轴后部](./previews/core-services.png)。这些是外景层次调整，不代表防护、承压或载荷已验证。

## R/11 固定主轴舱体与分区

五段固定舱体沿原布局分别表达人员支持、检查转运、分析保存、设备服务和能源服务，原中心、总长与筒段最大直径保留；端部在原长度内做短收肩，前两段共用X=−44 m接合区。原平面卡片覆板换成16个周向分区的弧形薄板，普通板底外偏60 mm、板厚25 mm、接缝35 mm，相邻分区错缝；纵梁、支环及既有附件根部留安装区。现有四条350 mm纵梁及16支撑站保留，支环按收肩后的局部壳半径贴合。

人员舱有两处小关闭窗面与防护盖，检查舱和分析舱有封闭传递／样品接口；各段维护罩具有槽底、槽壁、压框、盖板、铰座及锁扣。槽底在壳面之外，未切穿压力壳。两处顶部设备盒改为带弧形底座和短支脚的设备包，后段增加两处较小设备包；五段重复金色底盒撤除。灰白覆板、次级灰盖板与服务灰机箱分别使用独立主轴材质，共享材质和其他子系统布局保留。

设定正文见[固定主轴分区与外部构造](../../../docs/superpowers/specs/2026-10-06-romantic-ring-station-design.md#11-固定主轴分区与外部构造r112026-10-08)，外景工作值不代表承压、强度或设备容量已核定。预览：[前部舱体](./previews/core-detail.png)、[后部设备区](./previews/core-services.png)、[检修槽近景](./previews/core-recess.png)。

## R/10 主环内缘承力结构

按用户确认的贴壳周向梁、接口浅支撑和四处加强节点路线实施，同时控制新增结构的体量与反光。两条250 mm周向梁沿X=±7.15 m、中心线半径44.72 m布置，每个舱段分5节，共160根连续闭合梁段；普通梁节用80 mm短座接入壳体结构位置，普通接口以120 mm横向弦和70 mm短斜撑形成浅框。接口最深中心线向内偏420 mm，新增结构实际顶点的最小半径约44.217 m；与112/90 m名义压力壳尺寸另计，没有形成独立的大型内桁架圈。

四处大节点中央留出约9.1 m的轴向开口，两侧浅框保留；140 mm支撑从四个真实辐条端弦位置分散到相邻周向梁节点，并从入口支路两侧接入已有侧面端框角点。新增构件使用偏暗的灰色金属，沿用实例化与平直杆截面，独立子组挂在主环旋转组内。参数在`layout.working.mainInnerSupport`；250 mm沿用已有周向弦外宽，新增短座/横向框/支撑尺寸为外景工作值，未新增载荷核算，不能宣称整环刚度、承压或连接强度已验证。

预览：[整环](./previews/main-ring.png)、[内缘梁与接口](./previews/main-inner-support.png)、[辐条加强节点](./previews/main-support-node.png)。临时检查读取生产实例矩阵，核对两侧160根闭合梁段、主环挂载和真实顶点半径，并以有向包围盒核对新构件与两组人员通路的10个入口/支路/侧面登乘舱包络，未见相交；这不是全站碰撞或运行验收。构建、素材与截图记录见[主页开发记录](../../../docs/development/station-homepage.md)。

## R/09 生态主环外覆层与装配接口

按用户确认的灰白分块防护壳方向，主环保留16组舱段及段间桁架节点。约3 m接口区改为灰色连接颈、两端窄接环与分块维护护罩，侧面继续露出交叉杆件；护罩有铰座、锁扣、安装板和小紧固件。外缘、内缘、两侧及四个转角铺设薄覆板，平面板缝错开，名义接缝45 mm；外缘平面板约3.455×3.06 m（端部半片约1.51 m沿环），侧板约2.288×2.63–2.88 m，转角采用贴合既有2 m圆角的成形覆板。普通覆板外露厚度25 mm、底面距原壳面65 mm，均为美术外覆层工作值，不代表板材实厚、压力壳厚度或已核定的隔热/防护间隙。

灰白涂装覆盖原先宽大的裸露金属亮边，内缘服务带采用次级灰色；金属集中于接环、压框和安装件。观察侧保留小窗与收起防护盖，维护侧多数窗口关闭，配检修盖与封闭接口；既有循环设备节点增加可拆盖板。压力壳名义外径112 m、内径90 m，轴向18 m、径向11 m、四辐条及双旋转分组沿用R/08；外覆板和接环另有约90–130 mm的局部外偏，不能把这些附件尺寸当作压力空间净空。

新增`arcPanelGeometry()`只由主环使用，按轮廓法线生成薄板、独立折边及硬边端面。UV0按2 m基准表示表面纹理尺度，UV1完整映射每块板的边缘和小紧固件；主环单独使用程序化涂装材质，旧`arcGeometry()`和其他部件材质默认行为保留。重复板件继续按几何和材质实例化，无新增依赖、外部纹理或动画。

近景与整环预览见[主环整体](./previews/main-ring.png)、[装配接口与覆板](./previews/main-hull.png)。本轮验证记录见[主页开发记录](../../../docs/development/station-homepage.md)。

## R/08 杆件与支撑

采用用户确认的中档截面研究：[计算脚本](../../../docs/design/torifune-truss-sizing.py)、[计算记录](../../../docs/design/torifune-truss-sizing-results.json)、[实施计划](../../../docs/design/torifune-truss-sizing-implementation.md)。`layout.working.structuralSections`记录外宽与候选壁厚（米）；实例几何表达外包络，不能据网格体积计算实心金属质量。

- 主轴四条纵梁350 mm，分段接入16处贴合固定舱壳/轴承框的承力环和短支座，最大支撑间距9 m。用户选择此路线以避开直线斜撑穿舱；压力壳、支环和连接座的刚度仍待核算，不能把理想侧向约束直接当成已验证条件。
- 主环辐条主弦280 mm、副环300 mm，轴向侧面斜撑160 mm；主弦按受约束节段连接。主环局部周向主弦250 mm、16.4 m横向端框梁450 mm；副环周向主弦280 mm保留，实际挂载位置的6.8 m横梁加强到250 mm。主环承压接口仍由压力壳和承力接环承担，不将外露细杆当承压结构。
- 能源主弦200 mm，新增100 mm竖向侧面斜撑；光伏桅杆50 mm主弦保留，受压斜撑25 mm，并补齐窄面的斜撑和末端框。
- 四副散热器各增加600 mm深的连续背部箱形桁架，80 mm主弦、60 mm斜撑，六段板面经短安装杆连接；根部四支脚接入既有驱动框。原6×40 m板面与XZ镜像关系保留。
- 推进平面框650 mm局部径向梁及其他未经本轮局部核算的重载接口保留；650×35 mm等壁厚属于候选研究值，没有重建发动机推力路线。

中档质量场景为主旋转组3000 t、副组约4633 t、固定及推进组4000 t，推进/横向加速度分别假定0.03/0.01 m/s²。副组质量由简化角动量条件推得，库存容量与真实质量分布未验证。高档6000 t主环需要更大的部分环上构件，未在当前模型实施。承载、屈曲和挠度结果均附带材料、接头、侧向约束等假设；完整结构、热应力、动力学与承压性能仍待核算。

## 独立运行

现有依赖可由上级 `experiments/station/node_modules/` 解析。全新检出时在本包安装：

```sh
npm --prefix experiments/station/ring-romantic ci
npm --prefix experiments/station/ring-romantic run dev
```

访问 <http://localhost:26106/>。旧稿使用 26105，不需要关闭其他已有服务。

```sh
npm --prefix experiments/station/ring-romantic run build
npm --prefix experiments/station/ring-romantic run preview
```

若本机文件监听额度耗尽（`EMFILE`），可先 build 再 preview；需要开发热更新时可用 `CHOKIDAR_USEPOLLING=1 npm --prefix experiments/station/ring-romantic run dev`，无需调整模型或依赖。

## 当前结构

- 16 组弧形圆角舱段与大小服务节点交错，周向承力构件嵌入同一径向带，四组开放桁架辐条接入加强节点。两侧服务面具备小观察窗、关闭防护盖、封闭取样口、隔离阀箱、循环储液与沿辐条附挂的流体管路及封闭样品运输设施。外景没有植被、剖切或大面积透明舱。
- 前侧 84 m 副环设四个弧形舱段，其中两处为日常工作舱（储备管理/分装检查、设备维护/备件准备），两处为封闭储备仓。每段沿环 24 m，覆盖约 35°，轴向 6 m、径向 4 m，分块覆板、端框、小观察窗、防护盖、封闭舱门和维护设备区形成舱段轮廓。工作舱入口接两条相对的辐条升降设施，轴心有固定登乘位、机械托架和独立人员转接舱，采用与主环相同的静态同步构型。
- 副环外缘混合储存小型储液罐、封装基质/培养介质、可替换设备及耗材。试排 48 罐与 12 个混合托盘架（共 96 个封闭货包），保留四区段隔离管路、径向小货物通路、局部双轨与停驻搬运车；所有外缘设备随副环转，固定机械臂不直接抓取旋转外缘货物。流体周向管在前侧绕开人员升降罩，入口与邻近货架均已随扩大后的舱段避让。
- 固定轴线依次装配人员支持、检查/转运、分析保存、设备与能源服务模块；轴承壳、监测/驱动设备、固定侧服务接口与旋转端枢纽分别可读。
- 独立开放推进尾段含六主罐、四主机、挂接法兰、承力框、贮箱箍带/支座、阀箱、局部热防护与两类供给管路。交替的三罐燃料色/三罐氧化剂色仅为本轮外观分组，不代表工程配比。前后小喷嘴簇有独立单组元 RCS 储备与供给外形。
- 固定能源桁架两侧各两翼，共四组九段光伏翼；四组六段长条散热板保持 YZ 板面，每侧沿 ±Y 对称伸展，根部直接挂在同一光伏桁架上，与 XZ 光伏面垂直。根部转动机构、展开支撑、设备托盘、电气路径、散热背筋和集流管分别建模。
- 前端固定六向节点（后口连接主轴，前口与四个径向口提供对接外形）的载人与货运接口包含捕获环、关闭舱门、锁紧件和导航传感器。两支臂均挂固定组的移动底座，分别表现装配和检修姿态，附双轨、供电/锁定设施、空闲停靠位与货物托盘。主环四处局部轨道/基座与副环的备用基座随各自环转动，未宣称两臂覆盖全站。
- 主环两条相对辐条增加连续通风导引罩、气密升降舱、旋转侧接收颈及入口隔离舱，两条轴向支路接入现有两侧服务带。轴心有固定登乘舱、环形机械导轨/托架和独立挂载的人员转接舱；其他两条辐条保留设备/物料运输用途。
- 主通信碟有抬高支架、馈源、背筋和独立指向枢轴，由查看器朝向背景地球；辅助天线与相机保持次级体量。

## 主环人员进入方式（R/05）

用户确认采用 [NASA 概念研究中的旋转接口与气密升降舱](https://ntrs.nasa.gov/api/citations/19890009140/downloads/19890009140.pdf)，先落实主环。本版本适配现有固定核心：轴线通道保持贯通，在轴心附近设置环形机械托架与独立转接舱；这不是对论文结构的逐尺寸复刻或飞行验证。

计划的运行顺序：

1. 转接舱停在固定登乘位，与固定端锁定、密封并确认压差后开门，人员进入。
2. 关闭舱门、脱离固定端；在独立驱动控制下逐渐匹配主环转速。
3. 与旋转侧接收颈对准、锁定、密封后开门，人员进入气密升降舱。
4. 升降舱沿辐条导引设施移动，到环上入口隔离舱停稳后进入服务带；进入生态区另经隔离门。返回按相反顺序执行。

通过每一道舱门时，两端相对静止并密封连接。主环可以保持转动，人员无需跳跃、追门或暴露在真空中；同步与货物转移带来的载荷和角动量变化尚需控制设计。

模型展示的是已与主环同步的静态接驳/行进构型：独立转接舱当前跟随主环的展示角度，两侧舱门关闭，固定端接口断开。没有实现上述状态机、停靠伸缩段、舱门动作、压差控制或人员动画；用户已明确不需要这些动画，外景保持克制、稳定的运行展示。气密升降舱与非加压导引罩分别表达，护罩已按用户反馈从约 0.9 m 间隔收紧为 0.025 m 名义接缝，形成连续轮廓。它们与原桁架一起旋转；固定登乘舱留在固定核心。周向服务通路沿用现有环壳与封闭段间连接，入口通过轴向支路接两侧服务带，未新增独立环形大走廊，生态内部未制作。

R/05 当时仅落实主环；R/06 已补副环人员通路与两处工作舱。固定核心功能舱与原服务通道的尺寸继续保留。

## R/06 双环尺度、副环工作区与工业表面

用户确认副环外径 84 m、转速目标约 2 rpm，随后要求主环壳体内径略大于副环最外缘，并允许增大主环。主环外径由 100 m 增到 112 m，保持 11 m 径向包络，壳体内径由 78 m 变为 90 m；环上设备、节点、周向连接、辐条出口和人员入口向外移 6 m，轴心不动。地面参考半径同步由 48 m 变为 54 m，主生态目标仍为 0.16 g。正面截图使用临时正交镜头验证轮廓关系，产品默认镜头保持前侧 Z 轴基准 30°；透视视角中的遮挡仍随距离与观察方向变化。

副环两处工作舱用于日常工作，不改变固定核心主分析实验室的职责。两工作舱各经气密升降舱沿辐条进入，固定登乘位、独立转接舱和随环机械托架分开挂载，过门仍要求相对静止、锁定和密封。模型显示已同步的关闭构型；仓内桌面/家具、生命保障与舱门状态机没有建模。其余两仓段为封闭储备，日常小件由随环轨道、搬运车及径向物料设施运送，货物跨固定/旋转接口的内部机构尚未验证。

四舱段从 7 m 小占位增到沿环 24 m / 约 35°，轴向 6 m、径向 4 m。每个区段预留三库位给舱段，货物不再贴着或嵌进舱壁；原近舱零散外货架移除。液体只占每区段两组，其他库位分别放封装基质/培养介质、可替换设备、耗材，托盘、锁定、抽取面、隔离阀与标签分别表达。载荷保持外缘集中，但数量和外形不证明目标惯量已经具备。

按共轴稳态角动量近似，现有重力与转速目标要求 I副 / I主约 0.814。若主环质量等效半径为 51–54 m、副环为 39.2 m，集中质量试算要求副环质量约为主旋转组的 1.38–1.54 倍；该半径范围与质量比例只是条件估算，并非实测质量预算。此前 100 m 主环下的比例不能直接沿用。2 rpm 时副环名义外缘速度约 8.80 m/s、等效重力约 0.188 g，储位半径处约 0.175 g；舒适性、压力与配平仍需工程验证。

主轴和两环舱段表面补裸露金属压力壳、分块覆板、不同涂层颜色、环筋/端框、接缝、紧固件、检修盖及导管。主环外缘每段有 3×3 覆板，侧面保留观察/取样接口；主轴覆板按长度分段，反光和粗糙度有局部变化。副环同样采用金属壳与弧形覆板，小观察窗标识人员工作区。采用现有 PBR 与确定性程序化贴图，无新增外部纹理、依赖或后处理，保持维护正常的工业表面。默认远景发现薄覆板与压力壳显示交错，截图对比排除阴影后定位为深度精度不足；相机近裁面由 0.1 m 改为 1 m，保留正常阴影与既有镜头位置，复查无斑点。

## 文件与接口

`src/station-ring.js` 协调装配与动画，返回 `object`、`markers`、`envelopes`、`aimAntennaAt(worldTarget)` 和 `update(time)`。标记保存同一个站体局部 Vector3 引用，每帧从真实挂点更新；包络是站体子组，仅切换可见性。

`src/model/` 中 layout 集中参数，resources 管理本版本几何与材质，assembly 提供零件实例化、圆角弧壳、杆件、曲管及两环共用的连续导引罩/气密升降舱几何辅助。main-ring、counter-ring、core、propulsion、energy-thermal、operations 分别构造部件和挂点，由入口挂入所属结构组；构件文件彼此不导入。重复件按各组分别批处理，查看器统一释放几何、材质、纹理与实例化资源。

查看器保留暂停、减少动态效果、隐藏页面、拖动/键盘观察、纯净画面、初始视角、包络控制及 WebGL 恢复设计。标签在手机上仅显示主副环，包络均为未核算的候选空间。

每侧四个电池抽屉箱、一个充放电控制托盘、两个配电托盘（每托盘两个设备盒）、一组双泵与一个冷却补偿罐、一个备件托盘、一台停驻检修小车及一个翼根控制箱。设备通过座板、跨桁架横梁或安装支脚接入承力框；沿桁架增加电缆槽、冷却供回管、连接管路及窄维修导轨。翼根仍有两套独立安装/驱动外形，重设备靠内，外段保持开放。设备数量为外形工作值，不据此宣布储能容量或冷却冗余已经验算。

### 次级杆件的制造尺度整理（2026-10-08）

主轴纵梁550 mm、主/副环辐条主弦380 mm、储备环周向主弦280 mm、能源桁架主弦400 mm及主推进承力框保留。普通支架主要采用40/50/60/80 mm，较长次级杆100/120 mm，重设备支柱/翼根支臂160 mm；轻附件15–30 mm。主环节点次级框140 mm、压力仓段支承300 mm等属于独立承力节点，不按小设备支架统一缩细。机械臂杆、气密通道、样品运输罩和流体管路保持各自尺寸。

能源桁架横杆80/60 mm、斜撑120 mm；设备托盘横梁80–100 mm；光伏桅杆主杆50 mm、次级杆20–25 mm；散热边筋50×25 mm、斜筋30 mm；通信碟支柱160 mm、斜撑80 mm；小储罐/货架支架50–100 mm；前/后RCS支臂50/80 mm。泵组座板及支脚同步调整连接高度。结构杆使用平直盒形几何，取消单位圆角几何被轴向拉伸产生的长端部过渡，宽气密通路与设备罩保留圆角形体。

这是按常见制造规格收敛外截面的外景工作值，不等于选定实心钢材、壁厚、材料牌号、受压稳定性或载荷已经验算。长弦杆按分段装配理解，杆件存在接头也不等于其受压有效长度自然缩短。

参考：SSAB Domex Tube 460MH产品表（100×50、120×60等管材）、SSAB Domex Tube 500MH供货长度（标准6 m/12 m）、Atlas Tube Jumbo HSS（最大22英寸方管）、NASA FAST Mast Structural Response to Axial Loading（20120008187）。其中ISS太阳翼FAST的纵杆中段12.7/约15 mm，柔性横撑约7×9.5 mm，与米级主桁架的杆件不是同一类；本文光伏桅杆50 mm仍为较保守外景值，不能据此宣称复现FAST设计。
