# 鸟船科研站独立样稿

独立 Three.js 美术样稿。正式网站的页面、路由、依赖和部署配置均未接入此目录。

当前默认展示已选用 A 布局的 A / 19 外观细化样稿：纵向主梁、错位生态单元、服务组、循环处理、推进与能源热控占位。它用于检查空间关系，尚未完成压力结构、发射方式或动力预算。旧双环模型保留在 `src/station.js` 作为历史渲染参考，默认不加载。见 [设计进展记录](../../docs/design/torifune-design-progress.md) 与 [科研站结构草案](../../docs/design/torifune-structure-draft.md)。

## 运行

```sh
npm --prefix experiments/station ci
npm --prefix experiments/station run dev
```

访问 `http://localhost:26105/`。同一端口不能同时运行原网站开发服务。

```sh
npm --prefix experiments/station run build
```

## 样稿内容

### 当前 A / 19 外观细化样稿

- 模型单位按米使用。生态区研究基线为 8 米局部净高、10 米候选内径；体块外径暂取 10.8 米，属于包络工作值，不表示压力壳和防护已设计。
- 林地/湿地直筒段暂长 14/9 米，端部使用简化封头占位；舱长、截面、制造与运输方式未定。
- D/H/M 服务组、Q/N 隔离与分配、E-A/E-B 生态单元、R 循环处理、T 主桁架、P 推进及 W 能源热控有体块和标记。
- 当前纵向骨架工作跨度 58.4 米，服务/通道段位于压力通路外围，后段收窄到贮箱之间；生态舱通过端部环侧接。能源支臂采用空间桁架占位，强度与质心未核算。
- 推进段设四个直径 4.6 米、直筒段 5.6 米的贮箱占位，包含安装座、供给设备平台、管路、推力框和两个放大的喷口。数量及尺寸未根据推进剂类型、总质量、比冲、推力和目标变轨核算。
- A / 03 按已确认的可储存双组元化学推进方向补充燃烧室外壳、安装环、开放推力框、独立隔热屏、双路供给管线、阀组和增压气瓶占位；前后四组姿控组件暂有 16 个喷嘴。具体推进剂、供给方式、推力和喷流避让仍待核算。
- A / 04 主喷嘴改用平滑钟形曲线，分为喉部/上段夹套与下段延伸段，增加细纵向加强纹、接缝卡箍、薄出口边和深色内壁；轮廓与壁厚用于视觉表达，未计算膨胀比和冷却。
- A / 05 加入前端人员对接前室与侧向货运检查暂存舱，接口包含捕获环、锁紧/导向件、关闭舱门、被动目标和传感器占位；操作包络分别显示两条接近区域。具体对接标准、来访飞船外廓、载荷及喷流未核算。
- A / 06 加入主桁架外侧约 40 米双轨、移动底座及约 13.5 米外形尺度的半展开主臂，带抓取头、相机、设备托盘与承力安装座抓取点。操作包络含候选折叠区；未实现轨道运动、逆运动学或碰撞验证。
- A / 07 修正生态舱遮挡：保留下方运输轨道，增加两舱外侧检修基座和林地前方转接点，主臂移至湿地外侧，以双端抓取头表达换位方式。操作包络区分外侧作业区；未验证换位动画或无碰撞路径。
- A / 08 同时展示两支相同规格机械臂：下方轨道上的运输装配臂、湿地外侧的检修臂。双端换基座设想不要求人员拆装整臂，但模型尚未实现运动、锁定或供电转接。
- A / 09 服务组上方加入口径暂取 7.2 米的对地通信主天线，具备抛物碟面、背部加强筋、馈源支架与方位/俯仰底座；导航及对接相机以少量小件占位。当前指向用于构图，未实现跟踪或通信链路。
- A / 10 抬高天线支柱，碟面和馈源作为整体绕独立枢轴转动；按场景中的地球位置校准开口方向，窄屏与窗口尺寸更新时同步。不代表真实地面站跟踪或机构限位仿真。
- A / 11 生态舱保留大部分实体外壳，加入实际开口的分格观察窗、壳体接缝、防护板和检修设备盒；窗口内以林木、水面和湿地植被占位帮助辨认科研用途。玻璃与压力防护未设计，内部为简化美术。
- A / 12 各舱段外壳按用途区分防护板、灰蓝服务面板、偏暖金属贮箱和局部隔热层，增加周向/轴向分块缝与端部检修盖。分块避开观察窗；表面参数与制造工艺未做工程设计。
- A / 13 补充本地电池片纹理、板翼边框/铰链、部署支撑与根部转动机构；能源连接处使用较深箱形空间桁架，附电气箱与线缆。散热器分五段，独立浅色板面、背部支撑和集流管路；当前仅静态表达。
- A / 14 能源设备桁架改用交错侧挂灰色托盘、不同体量电气盒、连接器及短线束，撤下大棕色柜体并保留中央空隙。
- A / 15 按用户指定坐标：太阳能翼法线 Y，散热器法线沿主轴 X。散热器板面、框架、管路和根部随姿态调整，展开包络更新。后续待办见 [会话交接](../../docs/design/torifune-session-handoff.md)。
- A / 16 增加防护板薄边与表面纹理，区分哑光涂层、冷灰金属与带包边/褶皱的隔热毯；观察窗补密封压框、紧固件、收起的防护盖及窗旁检修盒细节。玻璃独立排序且不投影，静态实例化保留原阴影属性。生态内部与循环套件暂缓，后续建议已记录于会话交接。
- A / 17 快速细化桁架：独立金属反射、带倒角型材、较细斜撑、端部套接件及主梁薄连接板/紧固件。保持现有拓扑和布局，未验证载荷。
- A / 18 撤去贮箱底部方盒，补开放纵横梁与支座连接、四个独立设备托盘和局部隔热挡片；供给干线避开支座横杆，保留发动机前隔热屏。贮箱与发动机位置沿用，载荷/供给性能未验证。
- A / 19 按用户选定的第二种路线撤下低位贯通底架，改为通路外围骨架、生态舱端环侧接与贮箱间窄骨架；运输轨道/机械臂基座和附属支架同步迁移。见 [骨架关系图](../../docs/design/torifune-axial-spine.svg)。
- 双侧光伏翼各约 12×24 米，合计平面包络 576 平方米；分段显示帮助辨认尺度，不表示已选择板翼制造/展开方式。有效电池面积、效率和功率未赋值。
- 双侧散热器各约 8×10 米，仍为包络工作值；没有完成热负荷与视野计算。
- 查看器支持部件标签、10 米参考尺、操作包络、初始视角、纯净画面、鼠标/触摸及键盘观察。包络按钮显示候选对接、检修、展开与喷流空间，范围未完成工程计算。
- 站体静止；暂停控制开场镜头和背景动态。重复静态零件按几何体与材质实例化，减少桁架细节的绘制调用。
- 当前结构查看器已撤下活动入口和 staging 链接；正式网页未改动。

### 历史外景探索

- 不完整的倾斜观测环、可缓慢转动的居住环、中央舱体、对接口、观测舱、太阳能翼、散热板、天线和维护飞行器。
- 金属、哑光外壳、深色玻璃、暖色舷窗，主光阴影与克制的辉光。
- 程序化星空、地球与带环形山的月球背景；所有模型和纹理在本地生成，无外部美术素材或 CDN 请求。
- 第二稿将空间站移到右侧，地球部分出画并压低对比，月球位于右上方；左下方叠放活动名称和两个入口，检查首页的信息层级。入口链接在新标签页打开现有 staging 网站。
- 第三稿将地球改为完整的远景圆盘，地月视大小保留艺术放大，两者直径比约为 3.66；加入静态银河尘带、少量柔光亮星和轻微呼吸亮度。星层置于不同深度，随镜头产生克制的视差。
- 第四稿采用更侧面的站体姿态，突出中央轴线上的舱段、双环间距、能源翼和尾部天线。
- 开场缓慢抵近；鼠标/触摸拖动观察，滚轮或双指缩放；画布获得焦点后可用方向键转动。
- 暂停运动、回到初始视角、纯净画面；尊重系统的减少动态效果偏好。

空间站设定于地月系统的拉格朗日点附近，具体 L1–L5 点位尚未指定。地球、月球与空间站是首页的固定视觉元素。当前背景天体位置、尺寸、光照和站体比例用于美术构图，不代表真实轨道距离或工程模拟；确定具体点位后再校准天体方向及视大小。人物形象及站内场景不在本稿范围内。

尺度参考：[NASA 地球与月球资料](https://science.nasa.gov/earth/facts/)、[NASA 地月 L4/L5 的几何关系](https://pwg.gsfc.nasa.gov/stargaze/Slagrng2.htm)。艺术放大用于保留可读的表面细节，不作为站点距离的计算结果。

## 文件职责

- `src/station-blockout.js`：当前 A 布局、工作尺寸、部件标记、操作包络及静态零件实例化。
- `src/station.js`：已撤回双环外形的历史程序化模型，不由当前查看器加载。
- `src/materials.js`：表面纹理、材质与反射环境。
- `src/space.js`：星空与程序化背景天体。
- `src/main.js`：渲染器、灯光、镜头、控制、后处理与释放资源。
- `src/style.css`、`index.html`：样稿查看器的轻量说明与操作入口。

Three.js 附加模块使用参照：[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html)。
